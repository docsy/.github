# Security policy

Do not report vulnerabilities in public issues, discussions, or pull requests.

## Before you report

- Read [Hugo's security model][hugo-security], which Docsy inherits.
- Confirm the issue is Docsy's own, not Hugo's, a dependency's, or a particular
  site's.
- Reproduce the issue under [supported versions][support].

## Reporting

Use GitHub's [private vulnerability reporting][report].

A maintainer triages your report privately; valid issues are fixed and disclosed
through a GitHub security advisory, which credits you unless you ask otherwise.
