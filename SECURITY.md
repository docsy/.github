# Security policy

Do not report vulnerabilities in public issues, discussions, pull requests, or
other public channels.

## Reporting

Use GitHub's private vulnerability reporting: the [docsy/docsy advisory
form][advisory-form].

A maintainer triages your report privately; valid issues are fixed and, when
warranted, disclosed through a GitHub security advisory, which credits you if
you accept.
