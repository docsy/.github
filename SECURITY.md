# Security policy

Do not report vulnerabilities in public issues, discussions, or pull requests.

## Before you report

- Read [Hugo's security model][hugo-security].
- Confirm the issue is Docsy's own, not Hugo's, a dependency's, or a particular
  site's.
- Confirm the issue falls under [official support][support].

## Reporting

Use GitHub's private vulnerability reporting: the [docsy/docsy advisory
form][report].

A maintainer triages your report privately; valid issues are fixed and, when
warranted, disclosed through a GitHub security advisory, which credits you
unless you ask otherwise.
